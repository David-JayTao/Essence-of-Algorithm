# 二、DP
分治vsDP:
分治是把问题拆成互不重叠的子问题，分别求解再合并；DP 是把问题拆成会重复出现的子问题，把子问题答案存起来，通过状态转移得到最终解。

递归、自底向上都只是实现方式，不是本质区别。

核心 ！闫式dp分析法嘿嘿嘿：
集合定义的核心！：每一个选法都能对应到状态表示的某一个维度！有泛化性，每一个最优子结构均能包含进去！

## 二一、背包问题(特殊的线性dp：沿着物品编号和容量推进)
### 1、01背包小结，物品不重复
###  分类（对f[i][j]的定义不同导致不同的初始化）
#### 1.1容量上限型dp
    f[0~n][0~m]全部初始化为0
#### 1.2精确体积型dp
    仅f[0][0]=0,其他全部初始化为-INF(不可达)，
    仅能从符合定义的（刚好装满）f[0][0]转移
#### 1.1.1二维写法f[i][j]
```
    for(int i=1;i<=n;i++)
    {
        for(int j=0;j<=m;j++)
        {
            f[i][j]=f[i-1][j];//
            if(j>=v[i])f[i][j]=max(f[i-1][j],f[i-1][j-v[i]]+w[i]);
        }
    }
    cout<<f[n][m];
```
#### 1.1.2一维写法f[j]，逆序枚举j
```
    //优化：每一层i仅于第i-1层有关
    //使用一维滚动数组，每次只保留i-1层，用于更新未i层
    for(int i=1;i<=n;i++)
        for(int j=m;j>=v[i];j--)
            f[j]=max(f[j],f[j-v[i]]+w[i]);
    cout<<f[m];
```
### 2、完全背包小结，物品可重复
#### 一维写法f[j],正序枚举j
```
    for(int i=1;i<=n;i++)
        for(int j=v[i];j<=m;j++)
            f[j]=max(f[j],f[j-v[i]]+w[i]);
```

### 3、01背包详解
![alt text](image-6.png)
状态集合划分时：和全概率公式的本质有点像，将当前状态进行划分，是否允许存在重叠部分要根据具体计算公式的性质来决定，如果max就可以重叠，只要覆盖完就行（最长公共子序列）
```
#include<iostream>
#include<algorithm>
using namespace std;

const int N=1010;

int n,m;
int v[N],w[N];
int f[N][N];
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++)cin>>v[i]>>w[i];
    
    //本质：递推
    
    //状态表示：f[i][j]
        //集合
            //所有选法
            //条件：从前i个物品里选，总体积小于等于j
        //属性：Max，Min，数量  
        
    //状态计算    
        //集合划分（对i，j当前集合进行不重合的完全划分）
            //选第i个物品，(前提是能选i，j>=v[i])
                //f[i-1][j-v[i]]+w[i](已经定了要选i，前i-1的最大值+v[i])
            //不选i
                //f[i-1][j],
        //状态转移方程（从前往后递推关系式）
        //f[i][j]=max(f[i-1][j],f[i][j-v[i]]+w[i])
    
    //f[0][0~m]==0,f[1~i][0]==0
    for(int i=1;i<=n;i++)//从前往后，从前i件物品里选
    {
        for(int j=0;j<=m;j++)
        //从前往后，在前i件物品里选时，总体积限制小于等于j，直至最大的m
        {
            f[i][j]=f[i-1][j];//一定存在
            if(j>=v[i])f[i][j]=max(f[i-1][j],f[i-1][j-v[i]]+w[i]);
        }
    }
    cout<<f[n][m];
    return 0;
}
```

# 三、贪心
## 1、区间选点
数轴上选择尽量少的点，使得每个区间内至少包含一个选出的点。
## <=>最大不相交区间数量（活动选择问题）
在数轴上选择尽可能多的区间，使得选中的区间之间互不相交（包括端点）。
**法一、按左端点排序 + 动态收缩右边界**
* `st`、`ed` 记录当前的交集区间，随时更新；
* 包含加入的区间时，更新为新的最小完整交集区间
*  当不包含加入的区间时，结果加1，区间变为新区间
```
int cnt(vector<PII>&segs)
{   
    int res=0;
    int st=-2e9,ed=-2e9;
    for(auto seg:segs)
    {
        if(ed<seg.first)
        {
            res++;
            st=seg.first;//此行不更新也不影响结果
            ed=seg.second;
        }
        st=seg.first;//此行不更新也不影响结果
        if(seg.second<ed)ed=seg.second;
    }
    return res;
}
```

**法二、按右端点排序 + 遇到不包含的新区间时计数加一（每次选择最早结束的活动）**
![alt text](image-4.png)
### 1.1区间选点时的贪心证明
*(选择尽量少的点，使得每个区间内至少包含一个选出的点)*
* $Ans \le cnt$，显然；
* $Ans \ge cnt$，$cnt$ 个点覆盖了 $cnt$ 个独立的区间，想要覆盖所有的区间，则 $Ans \ge cnt$；

###  1.2最大不相交区间数量的贪心证明：
* 已找出 $cnt$ 个不相交的子区间，且这 $cnt$ 个区间的 $cnt$ 个右端点能覆盖所有区间，$Ans \ge cnt$，显然；
* 欲证 $Ans \le cnt$，**反证法**：
  * 假设 $Ans > cnt$，最多有 $Ans$ 个不相交子区间，至少要 $Ans$ 个点才能覆盖所有区间。
  * 这与仅需 $cnt$ 个点就可覆盖所有区间矛盾！
